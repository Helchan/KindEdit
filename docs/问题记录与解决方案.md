# 问题记录与解决方案

本文档记录 KindEdit 开发过程中发现的重大问题、重复问题、复杂修复、跨平台问题、性能问题、数据安全问题和构建打包问题。普通小修和无复用价值的一次性问题不记录，避免文档噪音。

## 2026-06-04 配置默认字体值前后端不一致

问题现象：

- 设置弹窗“重置”使用的默认值为编辑器字体大小 14、树视图字体大小 13。
- Rust 配置结构在配置文件缺失或字段缺失时使用的默认值为编辑器字体大小 10、树视图字体大小 10。
- 首次启动、配置文件缺失字段和用户点击“重置”后的字体默认表现可能不一致。

触发条件：

- 首次运行且没有配置文件。
- 配置文件存在但缺少 `textFontSize` 或 `treeFontSize` 字段。
- 用户在设置弹窗点击“重置”。

原因分析：

- 前端 `SettingsDialog` 中维护了一份 `DEFAULT_CONFIG`。
- Rust `AppConfig` 中通过 serde 默认函数维护另一份默认值。
- 两侧默认值没有统一来源，也未保持完全一致。

解决方案：

- 本次任务仅编写规格文档，未修改产品行为。
- 已在 `docs/KindEdit-软件开发规格说明.md` 中按当前真实行为记录该差异。
- 后续修复时应统一前后端默认值，并同步更新规格文档。

影响范围：

- 影响设置默认值、首次启动配置加载和重置行为。
- 不影响文件打开、保存、会话恢复或编辑内容安全。

验证方式：

- 检查 `src/components/Settings/SettingsDialog.tsx` 中的 `DEFAULT_CONFIG`。
- 检查 `src-tauri/src/core/config.rs` 中的默认值函数。
- 修改后应执行 `npm run build`、`cargo check --manifest-path src-tauri/Cargo.toml`，如属于产品行为修复还应执行 `./build_package.command`。

## 2026-06-04 应用图标透明区域与折角质感问题

问题现象：

- 初版应用图标在深色圆角矩形底座之外保留了黑色直角背景，桌面显示时出现不符合图标轮廓的黑色方块。
- 后续手工绘制版本虽然去除了底座，但折角阴影和局部形状过于生硬，右侧插入光标位置也不协调。

触发条件：

- 使用带背景底座的生成图直接派生 Tauri 图标资源。
- 在原图上做简单几何遮罩或手工重绘复杂折角结构。

原因分析：

- 生成图中的底座、外部阴影和文档折角阴影混在同一位图中，简单透明裁切容易把黑色底座像素或阴影脏边带入最终图标。
- 复杂折角和纸张材质不适合用临时几何手绘替代，容易产生不自然的灰块和硬边。

解决方案：

- 最终保留第一版图标的圆角矩形底座和双文档主体，对圆角矩形底座外部应用透明遮罩；遮罩边界必须以最终 512px 图标输出为准二次收紧到圆角矩形可见边缘内侧，避免把底座外侧黑色阴影或暗背景一并保留。
- 使用临时 Python venv 安装 Pillow，并通过高分辨率圆角遮罩生成透明 PNG；底座低饱和暗色像素统一调整为中性 macOS 风格石墨色，避免整体呈现暗色主题图标观感。
- 通过 `npm run tauri -- icon` 从透明 PNG 重新生成 `src-tauri/icons` 下的 PNG、ICNS、ICO 和平台尺寸资源。

影响范围：

- 影响 macOS、Windows 和其他平台打包图标资源。
- 不影响编辑器功能、文件读写、配置、会话或用户数据安全。

验证方式：

- 在灰色背景上预览透明 PNG，确认石墨色圆角矩形底座之外透明、无直角背景，且第一版文档主体和折角阴影保持自然。
- 执行 `npm run build`、`cargo check --manifest-path src-tauri/Cargo.toml` 和 `./build_package.command`。

## 2026-06-05 应用图标底座主题感与主体留白问题

问题现象：

- 深色或石墨色圆角矩形底座会让应用图标呈现明显的暗色主题观感，不符合当前期望的纯文档图形方向。
- 双文档主体周围保留透明边距时，桌面和 Dock 中图标主体显得偏小，视觉焦点不够直接。

触发条件：

- 保留圆角矩形底座作为图标外轮廓。
- 以带边距的图标源图直接派生 Tauri 多尺寸资源。

原因分析：

- 底座颜色无论接近黑色还是中性石墨色，都会成为图标的主要视觉面积，弱化白色和蓝色文档层本身。
- 图标源图的有效 alpha 区域没有贴近画布边缘时，小尺寸图标中主体占比不足。

解决方案：

- 移除圆角矩形底座，仅保留后层蓝色文档页、前层白色文档页、折角、文本线条和插入光标。
- 使用 Pillow 重绘双文档图形和必要阴影，让双文档组合的 alpha 有效区域触达 512px 源图画布四边，同时保持四角透明。
- 折角必须采用接近旧版图标的自然卷曲结构：竖向卷曲边、弧形下沿和轻量柔和投影，避免使用硬三角和直线高光造成生硬灰条。
- 无底座图标不再要求双文档组合直接贴死画布边缘，应保留极小透明间隙并按高可见度主体边界视觉居中；后层蓝色文档必须被前层白色文档和折角遮住，不能在右上折角区域凸出。
- 双文档主体应保持偏竖向的文档比例，不能为了四边 alpha 边界完全等距而把文档主体压成接近正方形的卡片。
- 通过 `npm run tauri -- icon` 从无底座透明 PNG 重新生成 `src-tauri/icons` 下的 PNG、ICNS、ICO 和平台尺寸资源。

影响范围：

- 影响 macOS、Windows 和其他平台打包图标资源。
- 不影响编辑器功能、文件读写、配置、会话或用户数据安全。

验证方式：

- 在灰色背景上预览透明 PNG，确认图标无底座、四角透明、双文档主体为偏竖向文档比例，视觉上下留白和左右留白基本均衡，右上折角为旧版质感的自然曲线和柔和阴影，且蓝色后页不在右上折角区域外露。
- 执行 `npm run build`、`cargo check --manifest-path src-tauri/Cargo.toml` 和 `./build_package.command`。
